# Relational Database Design & Business Revenue Analytics (Oracle SQL)

**Oracle SQL | Relational Schema Design (DDL/DML), Analytical Queries, Revenue & User Retention**

---

## Project Overview

A full relational database implementation and business intelligence SQL script covering user registration, service/course enrollment, payment processing, refunds, and regional user distribution.

## Key Analytical Areas

- **Database Architecture:** Normalized relational tables with `PRIMARY KEY`, `FOREIGN KEY`, `UNIQUE`, and `CHECK` constraints.
- **Revenue & Payment Analytics:** Net revenue calculation, payment status tracking, and refund rate monitoring.
- **User Engagement & Retention:** Active vs. inactive user segmentation, completion rates, and regional distribution across cities (Baku, Ganja, Sumqayit).
- **Advanced SQL Techniques:** Multi-table `JOIN`s, `GROUP BY` aggregations, subqueries, and analytical ranking queries.
