# Behavioral Classification & Decision Tree Modeling (IBM SPSS Modeler)

**IBM SPSS Modeler | CHAID Decision Tree | Predictive Classification & Feature Importance**

---

## Project Overview

A predictive classification and behavioral segmentation workflow built in **IBM SPSS Modeler** using the **CHAID (Chi-squared Automatic Interaction Detection)** decision tree algorithm to identify key behavioral drivers behind performance outcomes.

## Methodology & Workflow

1. **Data Preparation & Auditing:** Missing value inspection, variable type validation, and target class structuring (`High`, `Medium`, `Low`).
2. **Exploratory Factor Analysis:** Evaluating correlations between engagement metrics (`StudyHours`, `Attendance`, `AssignmentScore`), behavioral indicators (`StressLevel`), and demographic attributes.
3. **CHAID Decision Tree Modeling:** Generating interpretable classification rules and evaluating variable importance rankings.
